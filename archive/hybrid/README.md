# 历史混合镜像流程

这里保留 CN R1 / Global 试装时的镜像修改工具和兼容补丁，便于核查历史产物与回退。它们不参与当前标准 Android 构建，不能作为新 ROM 的默认生成入口。

`tools/hybrid_policy.py` 是暂停前的 CIL 修正候选：27 项严格冲突在临时策略上已通过，后续去除 permissive 域及镜像接入没有完成验证。不得将它作为源码策略通过的证据。

固件锁继续使用仓库根目录 `firmware/`，原包提取器继续使用根目录 `tools/prepare-stock.py`。所有镜像处理必须显式传入独立输入和新输出目录。

历史说明保留在仓库 `docs/`；其中旧工具路径应映射到本目录 `tools/`。标准构建以根目录 `docs/BUILD.md` 为准。
