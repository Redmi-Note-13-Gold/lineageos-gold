# Global 开发版状态

更新于 2026-09-17。当前源码维护 Global OS3.0.5.0.VNQMIXM / Android 15 vendor / kernel 6.6.118，目标为 LineageOS 23.2。最新实机候选为 `userdebug-charger-final-20260916`；本次仅推送源码和文档，暂不重建、验证最新完整安装包，也不创建 ROM Release。

## 已纳入的修复

- 恢复启动阶段挂载与数据初始化配置，补齐 EGL 能力属性及图形库标签，解决本轮图形初始化和系统启动阻塞。
- 修正电源、传感器、指纹、振动服务标签，以及与正常系统实际节点对应的热管理配置。
- 补回无线模块加载和相关属性，完善指纹控制节点；恢复 modem 配置，并将 modem 运行目录、相机属性和权限修复写入提取配方。
- 关机充电等待驱动和 DRM 节点就绪后启动界面，设置节点权限与板级亮度，补齐读取电源信息的规则。最终版已移除自动返回 Recovery 的诊断脚本和临时日志修改。

## 已部署和观察到的结果

| 项目 | 实际证据 | 边界 |
|---|---|---|
| 镜像与安装 | 最终增量镜像完整 AVB 链通过，B 槽 14 项回读一致 | 构建目标为 vendorimage/vbmetaimage；不等于最新完整 OTA 通过 |
| 正常启动 | sys.boot_completed=1，Android 锁屏可见；开机 60.81–150.80 秒关键进程与启动标识保持一致 | 短时回归检查，不代表长期稳定性 |
| 数据与策略 | 加密 F2FS /data 和 persist 挂载正常，SELinux Enforcing | 前期启动修复曾经授权初始化 data；最后充电修复未再次清除数据 |
| Recovery | 保留现有自动开启 ADB 的 debug Recovery，充电修复未改动它或 A 槽 | 属于开发设备调试配置 |
| 关机充电 | 包含相同永久修复的 charger-display 诊断版已由用户确认看到充电图案 | 最终清理版未另测完整关机插电循环；熄屏后短按电源再显示也未单独确认 |
| 服务就绪 | 温控就绪、28 个物理传感器、4 个相机设备、双卡数据服务；蓝牙开启且无崩溃，指纹 HAL 无死亡 | 服务可用不等于实际功能验收；当时 Wi-Fi 未连接网络 |
| 日志窗口 | 91.4 秒内目标致命异常、电话 ANR、modem 断言、看门狗重启和本轮针对权限错误均为零 | 仍有 27 类其他 AVC 分组，不能称全部日志无错误 |
